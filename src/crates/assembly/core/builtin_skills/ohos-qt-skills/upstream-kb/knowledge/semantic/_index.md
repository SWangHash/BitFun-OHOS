- [qdrag-cancel-cross-platform](qdrag-cancel-cross-platform.md) — QDrag::cancel() 编程式拖拽取消的跨平台适配现状：Windows 和 X11 已实现（OLE flag / QBasicDrag 事件循环）， macOS (Cocoa) 和 OHOS 均未实现（cancelDrag 落到 Q_UNIMPLEMENTED 空操作）。OHOS 上调用不会崩溃/卡死但静默无效， 原生 drag 自然结束后 exec 返回。含官方 draggableicons 示例扩展 demo 和各平台 file:line 证据链。
