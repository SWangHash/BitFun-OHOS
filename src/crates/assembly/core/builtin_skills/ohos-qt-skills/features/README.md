# 把你的 skill 接入 Qt 鸿蒙迁移流程

本仓库的 skill 负责把 Qt 应用迁移到鸿蒙（HarmonyOS）。如果你有一个与鸿蒙相关的 skill，
可以把它接入迁移流程，成为一个**外部 feature**：迁移用户选用后，迁移流程会在合适的阶段执行你的 skill。

## 能接入哪两类 skill

| 类型 | 什么时候运行 | 适合什么 skill | 会不会改应用代码 |
|---|---|---|---|
| 鸿蒙能力 | 应用移植完成后（第 6 阶段） | 给应用加上鸿蒙特有能力，例如碰一碰、接续、分享 | 会，只在鸿蒙平台的代码分支内 |
| 验收流程 | 交付前（第 8 阶段） | 对最终安装包做额外检查，例如兼容性、合规、专项测试 | 不会，发现问题只记录，由迁移流程修复后再验 |

## 你需要准备什么

只需要一个完整的 skill：一个目录，里面有带 `name` 和 `description` 的 `SKILL.md`，以及它用到的脚本、参考文档等。
不需要写任何别的说明文件，也不需要了解迁移流程内部的记录格式。

skill 里写清楚下面几点，登记时就能少回答几个问题（都不是必需的）：

- 这个 skill 做什么、什么时候该用；
- 有哪些步骤；
- 怎样算成功：有没有判定用的脚本，或者会输出什么结果文件；
- 是否需要真机，需要什么设备；
- 需要哪些权限、SDK 或工具。

## 怎么登记

对维护本仓库的 agent 说一句话就可以，例如：

```text
把 D:\skills\nfc-share 这个 skill 登记为外部 feature
```

agent 会读你的 skill，然后用选择题问你几个问题：类型、名称、负责人、迁移用户会用哪些词提到它、
怎样算完成、是否需要真机等。每题都有从你的 skill 里读出来的推荐项，回答“都用推荐”即可。
之后 agent 会生成登记文件并自检，最后问你是否提交。

你的 skill 会原样保存在 `features/<feature-id>/skill/` 下，**不会被修改**，也不会往里添加文件。

## prompt 示例

| 想做什么 | 可以这样说 |
|---|---|
| 登记（最简） | `把 D:\skills\nfc-share 这个 skill 登记为外部 feature` |
| 登记时直接给出已知信息，减少提问 | `把 D:\skills\nfc-share 登记为外部 feature：鸿蒙能力类，负责人 team-x，需要两台真机，用户说“碰一碰”“tap to share”时推荐它` |
| 登记验收类 skill | `把 D:\skills\qa-acceptance 登记为外部验收 feature，交付前运行，负责人 QA 组，用 skill 里的 scripts/judge.py 判定是否通过` |
| 升级 skill | `把 harmonyos-nfc-share 的 skill 升级到 D:\skills\nfc-share-v1.3` |
| 发布给迁移用户使用 | `检查 harmonyos-nfc-share 能否发布，可以的话发布为 beta` |
| 修改登记信息 | `把 harmonyos-nfc-share 的触发词加上“NFC 分享”，负责人改为 team-y` |
| 查看 | `列出已登记的外部 feature` |

## 登记之后

1. **先是草稿**：新登记的 feature 状态为 `draft`，迁移用户看不到它。确认无误后，让 agent 检查并发布为
   `beta` 或 `stable`。
2. **迁移用户来选**：发布后，迁移用户在确定迁移范围时会看到它，由用户决定是否使用；不会自动启用。
   用户需求里提到你的触发词时，它会排在前面。
3. **按迁移流程的规则执行**：你的 skill 与迁移流程的规则冲突时，以迁移流程为准。例如执行中不联网安装依赖、
   输出写到迁移流程指定的目录、验收类 skill 只记录问题不改代码。登记时 agent 会把这些冲突列出来请你确认。
4. **升级**：交付新版本 skill 后让 agent 升级。正在进行、已经选用了你的 feature 的迁移，需要迁移用户确认后
   才会切换到新版本。

## 常见问题

- **我的 skill 会被自动触发吗？** 不会。它只放在本仓库的 `features/` 下，只有迁移用户选用后、到了对应阶段才会执行。
- **需要为接入改我的 skill 吗？** 不需要。登记需要的文件都写在 skill 外面。
- **我的 skill 自己有一套步骤或状态文件，怎么办？** 可以保留。登记时 agent 会说明哪些部分在迁移中按迁移流程处理。
- **验收 skill 发现问题会直接修吗？** 不会。验收只记录问题，修复交给迁移流程，修完后会重新运行你的验收。
