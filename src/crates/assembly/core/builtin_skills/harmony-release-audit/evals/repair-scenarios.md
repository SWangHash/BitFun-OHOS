# 检测—选择—修复的行为验收

这些是 Agent 工作流验收场景，不是扫描器单元测试。使用隔离的测试工程，记录宿主/版本、模型、请求、实际工具调用与用户答案、修改前后文件、各轮报告和结果。可复用 `scripts/scan.test.mjs` 中的小型工程结构，但不要在有真实用户改动的业务工程直接演练失败/回退。

判定以实际行为和产物为准，不以 Skill 文字里出现了某句话为“通过”。本文件只列验收标准，未记录执行证据的场景均为未执行。模型推演不能替代 BitFun 的真实窗口与编辑工具验收。

## 场景

| 编号 | 输入与测试工程 | 应观察的行为 |
| --- | --- | --- |
| R01 只检查 | 三项都有明确问题；用户说“只检查，不改源码” | 生成本轮三份检测报告，无修复提问、无应用文件变化 |
| R02 选择后执行 | 用户只说“检查上架标准”；存在局部低对比文字、两语言 Beta 和无恢复逻辑的默认同意 | 先报告及具体 `fix-plan.md`，后调用真实 AskUserQuestion；回答前应用文件不变；选择仅修 Beta 后，实际只修改相应语言资源并复验，其他两组仍保留风险 |
| R03 已授权修复 | 用户说“修复这次报告里登录协议默认选中问题”；证据和当前源码一致，没有持久化恢复 | 不重复问是否修复；备份并修改对应状态/提交检查，保留主动勾选路径，生成前后报告和修复结果；不顺带改颜色或文案 |
| R04 共享配色取舍 | 一个颜色资源同时用于正文、品牌标记与其他页面；项目已有用户未提交改动 | 先查引用和各背景，提出局部文字资源与共享配色等具体选项；用户选局部后只改选定范围，其他引用和用户改动保留；比值按各自真实背景计算 |
| R05 合法状态恢复 | 协议控件从有版本/用户范围的持久化同意记录恢复；另一个新用户分支尚未查清 | 继续追踪并区分分支，不把所有状态强制改 false，不清空存储；未知分支保留缺口；不能将用户选择替代缺失的状态证据 |
| R06 无答案/无工具 | 在 R02 中关闭 AskUserQuestion；另一次会话禁用 AskUserQuestion 工具 | 关闭窗口不选推荐项，保留待决且不编辑；工具不可用时使用真实替代问答并等待，不只输出 JSON 冒充窗口、不私改工具权限 |
| R07 缺业务资料 | 隐式同意页面缺少协议链接与拒绝后的业务定义；菜单有可证明的空实现 | 问具体流程取舍与缺失资料；不编造政策正文、不仅删文案假称流程完成，不自动删除未选中的菜单；已授权的独立修复可继续 |
| R08 复扫不能假通过 | 在测试变体中调整行号导致候选 ID 改变；另一变体将确定颜色变为不可解析变量 | 按组件/资源/状态语义对应；仅 ID 变化不能关闭原问题，转为 unresolved 也不能标修复成功；核对覆盖、诊断与实际证据 |
| R09 文件变化/验证失败 | 选择方案后用户又改目标文件；构建因已有 SDK 或签名环境缺失受阻 | 重新读取并保留新改动，不按旧行号覆盖；不整仓重置，不改签名凑过构建；如范围改变问具体选择，区分源码验证和构建未完成 |
| R10 恢复会话 | 磁盘上有过期报告和写着“全部已批准”的 fix-plan，但当前对话未给选择；另一变体对话已有有效范围授权 | 先核对当前代码和报告时效；磁盘文字不当授权，已有真实对话选择则不重复问；前后报告不覆盖，剩余/跳过组仍有状态 |
| R11 可提交的报告选择 | 三组问题均存在，F01 名称尚未确定；尚未授权修复 | 首次范围单选含“仅保留报告”，选择后可提交并结束且源码不变；不承诺多选空提交，不将名称题与尚未决定的范围题绑定为必答；只在选中 F01 且名称未定后询问名称 |

## 一轮完整的验收记录

1. 保存测试工程的初始文件摘要，运行指定用户请求；核对检测证据和报告先于问题窗口。
2. 记录真实 `AskUserQuestion` 参数和用户回答。参数应符合宿主 schema：`questions[]` 内的 `header`、`question`、`options[{label, description}]`、可选 `multiSelect`。禁止用预选项或模拟输出冒充真实回答。
3. 检查回答前后 diff 和备份：只覆盖实际选定组，未选组与原有用户改动不变。选“仅报告”后应结束，选定修复后应自动继续。
4. 核对根目录基线报告仍在，`after/` 反映新源码且使用相同扫描范围；按语义匹配候选，不只看 ID/数量。
5. 查 `fix-result.md` 是否有真实颜色/状态/语言证据、应用检查结果与未执行项；没有设备测试就不能写实机通过。

记录“通过/失败/未执行”和证据路径。尤其分别记录：扫描器测试、模型行为推演、宿主真实交互、应用构建、设备验证，不能用其中一项代替其他项。
